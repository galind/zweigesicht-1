# M0 proposed validation tolerances — v1

Proposed before the M0 extension probe, 12 September 2026. These are engineering screening targets, not agreed manufacturing tolerances or watchmaker approval. M0 establishes the budgets; M2–M4 must validate the measurement method and obtain review. No tolerance is permission to ignore known penetration.

Evidence: [mechanical review](../MECHANICAL_REVIEW.md), [CAD audit](../CAD_AUDIT.md), [hand fitting](../HAND_TIME_REVIEW.md), and [assembly manifest](../../explorer/public/models/assembly-manifest.json). STEP world coordinates use mm and right-handed world +Z angles. Decimal digits in transforms are not physical precision. The existing manifest reports a maximum valid-definition tessellation bounds discrepancy of 0.007474481 mm; display meshes alone therefore cannot certify micrometre contact.

| Quantity / scope and source IDs | Proposed threshold | Derivation and rationale | Confidence / approval |
| --- | --- | --- | --- |
| Immutable source/fitted matrix restoration; all instances, all 15 blades | Exact stored-base identity on restoration; computed matrix entries within 1e-10 (dimensionless rotation, mm translation) | Existing manifest/preflight transform difference is 2.84e-14; permits arithmetic rounding while catching repeated transforms. Test in double precision before GPU conversion. | Engineering numerical budget; proposed |
| Pivot/axis reconstruction; 113, 127, 234, 242, 237, 93 and newly probed shafts | 0.001 mm transverse axis disagreement; 0.01° axis direction disagreement | A 1 µm position budget is 1/35 of the 116 ribbon width. At 3.3 mm radius, 0.01° gives 0.000576 mm displacement. Much tighter than overview meshes; use analytic cylinders. | Engineering screening; not bearing clearance; proposed |
| Gear center-distance cross-check; 94/237, 238/242, 243/234 and candidate upstream/display pairs | Report residual; flag above 0.005 mm; also report uncertainty propagated from label module precision | Label module rounding can dominate: half last digit × sum(teeth)/2. The historical 0.000150 mm residual is not a fitted pitch-circle error. A passing center distance only nominates a mesh. | Candidate screening only; proposed |
| BRep contact classification; 233 against both 128s, 112/114 against 129/130 | Numerical ambiguity band 0.001 mm; require distance convergence within 0.0002 mm and explicit solid-intersection/contact-normal analysis | 1 µm is below visible ribbon detail and separates numerical uncertainty from apparent contact. Source topology tolerances must be measured before using it; if greater, classify inconclusive, never enlarge to pass. Zero distance alone is inconclusive. | Method-dependent, external contact review required |
| Penetration; escapement and all springs | No known unintended penetration; report depth and intersection volume with uncertainty, no positive allowed-depth budget | A small positive intersection may be numerical, so refine and classify rather than waive it. Intended press fits at fitted hand seats are separately documented static interfaces, not moving contacts. | Mechanical criterion; external review required |
| Terminal positions/orientations; 116 to 115 and 117/118, 88 to each 87/drum | ≤0.001 mm and ≤0.1° at complete terminal frame | Position is 2.86% of 0.035 mm ribbon width; orientation budget across 0.215 mm height implies <0.000376 mm endpoint deviation. Whole frames, not centers alone. Barrel terminal frames remain unknown. | Approximation quality budget; proposed |
| Ribbon arc length; 116 and each 88 | ≤0.1% relative change from independently recovered source centerline | Prescribed animation should not rely on appreciable extension. This is a strict authoring target, not an elastic-material model. Source centerline must converge to ≤0.02% between refinements first. Do not treat name “l290” as measured length. | Assumption; external plausibility review required |
| Spring cross-section; 116 | ≤1% width/height change from 0.035 / 0.215 mm | Prevents shear/scaling from masquerading as bending; validate cross-section orientation and overcoil topology separately. | Approximation quality budget; proposed |
| Visual close-up error; regulation and hands | ≤0.25 CSS pixel projected deviation at documented camera/viewport; provisional 0.001 mm geometry budget | Design inspection scale of 8 mm over 1600 CSS pixels gives 200 px/mm and 0.00125 mm per quarter pixel. This is an intended test scale, not a current viewer measurement; record actual scale and tighten if needed. | Proposed visual budget; user review pending |
| Contact event sampling; one full cycle, both half-cycles | Refine until all monitored surface travel per interval ≤0.0005 mm and event time brackets ≤1e-5 s; halve again to check stability | Half the contact ambiguity band reduces missed short events. Angular/time steps must adapt to amplitude and speed; fixed 30-pose sampling cannot qualify. Continuous swept bounds are needed to exclude between-sample collisions. | Proposed method; M2 must demonstrate convergence |
| Deterministic evaluation / display progression | Same-input repeatability exact in one JS runtime; independent-path angle error ≤1e-10 rad up to 12 h; hand target comparison ≤0.01° | Separates numerical repeatability from visual tip-angle error. 12 h covers display rollover, not full power reserve. Rational ratios and bounded phase reduction avoid accumulated error. | M1/M6 engineering targets; proposed |

If a method cannot resolve these thresholds, its result is **inconclusive**, not a pass. Source BRep tolerances, actual close-up scale and spring centerline convergence remain required inputs. External review should ratify contact/anchor/length budgets before M4 mechanical acceptance. M0 completion does not claim that these proposals have been agreed.
