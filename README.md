# Zweigesicht

An interactive 3D exploration of Marco Lang's ML01 Zweigesicht watch movement.

The project uses Marco Lang's published CAD to let visitors inspect the complete movement, reveal its functional groups, explore individual components, and understand selected mechanisms in motion.

## Current status

Preflight is complete and the project is ready for the first CAD audit and interactive prototype. See [PROGRESS.md](PROGRESS.md) for the current execution state and [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) for the staged plan.

The original CAD downloads are intentionally excluded from Git. Their source URLs, sizes, and hashes are recorded in `assets/source-manifest/sources.json`.

## Working locally

The verified environment, CAD conversion, and browser smoke-test commands are documented in [PREFLIGHT_REPORT.md](PREFLIGHT_REPORT.md). The unattended execution protocol is in [UNATTENDED_RUN.md](UNATTENDED_RUN.md).
